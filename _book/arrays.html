10  One-Dimensional Arrays

The exercises should be solved without converting numbers to strings. In the exercises, do not use double pointers or equivalents of multi-dimensional arrays — the syntax should use a single dimension only. In the exercises, do not consider an array of size zero, as size-related arguments are positive.

  1. Write a function findMaxValue that takes as arguments an integer array numbers and its size size (a positive integer). The function should search the array and display the maximum value found in it. Create a test case.

  2. Write a function average whose arguments are a positive integer \(n\) and an \(n\)-element array tab of elements of type int, and returns the arithmetic mean as a floating-point number. Create a test case.

  3. Write a function sumSquares whose arguments are a positive integer \(n\) and an \(n\)-element array tab of elements of type int, and returns the sum of squares of the array elements. Create a test case.

  4. Write a function copyArr that takes three arguments: a positive integer n and two n-element arrays tab1, tab2 of elements of type int, and copies the elements of array tab1 to array tab2 in order. Create a test case.

  5. Write a function revCopy that takes three arguments: a positive integer n and two n-element arrays tab1, tab2 of elements of type int, and copies the elements of array tab1 to array tab2 in reverse order. Create a test case.

  6. Write a function reverseArr whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should reverse the order of elements in the array tab directly in place, without using an additional array to store results. Create a test case.

  7. Write a function maxValue whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should search the array and return the largest value found in it. Assume the array is not empty. Create a test case.

  8. Write a function minValue whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should search the array and return the smallest value found in it. Assume the array is not empty. Create a test case.

  9. Write a function maxIdx whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should find and return the index of the largest element in the array. If more than one element has the maximum value, the function should return the index of the first one (i.e., the smallest possible index). Assume the array is not empty. Create a test case.

  10. Write a function minIdxMax whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should search the array and return the index of the smallest element in the array. If there are multiple identical smallest elements, return the largest possible index among them. Assume the array is not empty. Create a test case.

  11. Write a function shiftLeft whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type float. The function should shift all elements of the array one position to the left, and the last element in the array should be replaced by the first element of the original array. Assume the array is not empty. Create a test case.

  12. Write a function shiftRight2 whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should shift all elements of the array two positions to the right. Elements that “fall off” the end of the array should appear at its beginning in the same order. Create a test case.

  13. Write a function shiftLeft whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should return a pointer to a newly created dynamic array in which all elements have been shifted one position to the left relative to the original array, and the last element of the new array equals the first element of the original array. Create a test case.

  14. Write a function shiftRight whose arguments are a positive integer n representing the array size and an n-element array tab of elements of type int. The function should return a pointer to a newly created dynamic array in which all elements have been shifted one position to the right relative to the original array, and the first element of the new array equals the last element of the original array. Create a test case.

  15. Below is code in the C language. Some lines contain comments. Your task is to fill in the values of the corresponding variables after each specific line of code is executed. Adding new lines or disrupting the code structure means incorrect completion of the task.

#include <stdio.h>
#include <stdlib.h>

int foo(int*a,int*b)
{
    return *a-*b;
}

int main()
{
    int tab[] = {3,3,0,0,3,3,-4,-4,0,1};
    int *wsk=tab-1;
    int b = *(wsk+=4); //b=
    int c = b+3; // b=  , c=
    int d = foo(&b,&c); // b=  , c=  , d=
    int e = (wsk+=-1)[4]; // b=  , c=  , d=  , e=
    e = (d *= 2) + (c += 2); // b=  , c=  , d=  , e=
    c = d + (b+=4); // b=  , c=  , d=  , e=
    e= (--c)-(d++);  // b=  , c=  , d=  , e=
    b = *wsk + e; // b=  , c=  , d=  , e=
    return 0;
}
  1. Below is code in the C language. Some lines contain comments. Your task is to fill in the values of the corresponding variables after each specific line of code is executed. Adding new lines or disrupting the code structure means incorrect completion of the task.
#include <stdio.h>
#include <stdlib.h>

int foo(int*a,int*b)
{
    return *a-*b;
}

int main()
{
    int tab[] = {1,5,5,2,3,3,-4,-4,0,1};
    int *wsk=tab-1;
    int b = *(wsk+=4); //b=
    int c = b+3; // b=  , c=
    int d = foo(&b,&c); // b=  , c=  , d=
    int e = (wsk+=-1)[4]; // b=  , c=  , d=  , e=
    e = (d -= 2) - (c += 2); // b=  , c=  , d=  , e=
    c = d + (b+=4); // b=  , c=  , d=  , e=
    e= (--c)-(d++);  // b=  , c=  , d=  , e=
    b = *wsk + e; // b=  , c=  , d=  , e=
    return 0;
}

  1. Write a function called findElement that takes as arguments an integer array, the array size, an integer val to find, and a pointer to a function isEqual. The function isEqual takes two integers as arguments and returns a value of type 0 or 1, indicating whether the numbers are equal, respectively. The function findElement should search the array to find the value val according to the rules defined by the function isEqual, and then return the index of that element in the array (the first one encountered) or -1 if the element does not exist. Create a test case for the function findElement.

  2. Write a function findWithCondition that takes as arguments an integer array, the array size, and a pointer to a function condition. The function condition takes an integer as an argument and returns a value of type 0 or 1, indicating whether the number satisfies a specified condition. The function findWithCondition should search the array to find the last number satisfying the condition defined by the function condition, and then return the index of that element in the array or -1 if no such element exists. Create a test case for the function findWithCondition.

  3. Write a function isSymmetric that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should return the value 1 if the array tab is symmetric (i.e., the first element equals the last, the next equals the second-to-last, etc.) and return zero otherwise. Create a test case for the function.

  4. Write a function areArraysEqual that takes three arguments: a positive integer \(n\) and two \(n\)-element arrays tab1 and tab2 of elements of type int. The function should check whether both arrays are identical. If so, the function should return 1; otherwise, return 0. Create a test case for the function.

  5. Write a function indexOfMaxAbs that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int, and returns the index of the first occurrence of the largest absolute value among the elements stored in array tab. Create a test case for the function.

  6. Write a function rotateLeftByTwo that takes two arguments: a positive integer n (\(n>3\)) and an n-element array tab of elements of type double, and shifts all elements of the array two positions to the left (so that the value of the element at index n-1 ends up at index n-3, the value at index n-2 ends up at index n-4, while the value at index 0 goes to index n-2, and the value at index 1 goes to index n-1). Create a test case for the function.

  7. Write a function multiplyElementwise that takes four arguments: a positive integer n, n-element arrays tab1 and tab2, and an n-element array tab3 of elements of type double. The function should compute the product of the elements of arrays tab1 and tab2 at the same indices and store the results in array tab3. Create a test case for the function.

  8. Write a function sumOddIndices that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should return the sum of the elements located at odd indices. Create a test case.

  9. Write a function countPositiveElements that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should return the number of positive elements in the array. Create a test case.

Example. For an array containing the elements 3,-4,5 the function should return 2.

  1. Write a function doubleOddElements that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should double the odd-valued elements in the array. Create a test case.

  2. Write a function increaseByIndex that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should increase the value of each array element by its index. Create a test case.

  3. Write a function multiplyElementwise that takes four arguments: a positive integer n, n-element arrays tab1 and tab2, and an n-element array tab3 of elements of type double. The function should compute the product of the elements of arrays tab1 and tab2 at the same indices and store the results in array tab3. Create a test case for the function.

  4. Write a function sumAboveThreshold that takes three arguments: an integer k, a positive integer n, and an n-element array arr of elements of type int. The function should return the sum of all elements of array arr that are greater than the number k. Create two test cases. Example: for k=10, n=6 and the array 4,12,3,15,8,25 the function should return 52.

  5. Write a function findFirstDivisibleIndex that takes three arguments: a positive integer p, a positive integer n, and an n-element array numbers of elements of type int. The function should return the index of the first occurrence of a number divisible by p in the array numbers. If no element is divisible by p, the function should return -1. Create two test cases. Example: for p=3, n=7 and the array 5,11,9,2,4,7,6 the function should return 2.

  6. Write a function countInRange that takes three arguments: an integer a, an integer b, a positive integer n, and an n-element array data of elements of type int. The function should count how many elements of array data fall within the interval [a,b] (including a and b). Create two test cases. Example: for a=5, b=15, n=8 and the array 3,7,22,10,5,18,9,4 the function should return 4.

  7. Write a function sumDivisibleBy3 that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should return the sum of elements divisible by 3, and zero if there are no such elements. Create a test case. Example: for the array 7,9,2,6,5 the function should return 15.

  8. Write a function productEven that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should return the product of even-valued elements, and 1 if there are no such elements. Create a test case. Example: for the array 3,4,5,2,7 the function should return 8.

  9. Write a function countNegInd that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should return the count of negative elements that are located at even indices of the array. If there are no such elements, the function should return 0. Create a test case. Example: for the array -2,4,-5,-7,6 the function should return 2.

  10. Write a function minArrays that takes four arguments: a positive integer n, n-element arrays tabA, tabB, and tabC of elements of type int. The function should select the minimum value from the elements of arrays tabA and tabB at the same indices and store the results in array tabC. Create a test case. Example: tabA = {7,-2,14}, tabB = {9,6,-3} → tabC = {7,-2,-3}.

  11. Write a function sumArrays that takes four arguments: a positive integer m, m-element arrays array1, array2, and arrayResult of elements of type double. The function should sum the corresponding elements of arrays array1 and array2, and then store the results in array arrayResult. Create a test case.

  12. Write a function sumOdd that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should return the sum of odd-valued elements, and 0 if there are no such elements. Create a test case. Example: for the array 2,7,4,9,3 the function should return 19.

  13. Write a function multiplyByPosition that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function modifies the array by multiplying each element by its index plus 1 (the element at index 0 is multiplied by 1, the element at index 1 by 2, etc.). Create a test case. Example: array {2,3,4} → {2,6,12}.

  14. Write a function decreaseBySquare that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should decrease the value of each array element by the square of its index. Create a test case. Example: array {5,10,15,20} → {5,9,11,11}.

  15. Write a function replaceWithPower that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should replace the value of each array element with that element raised to the power equal to its index. For index 0, the element remains unchanged. Create a test case. Example: array {2,3,4,-3,-2} → {2,3,16,-27,16}.

  16. Write a function sumOddIndex that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should return the sum of elements at odd positions, and zero if there are no such elements. Create a test case. Example: for the array 3,-4,5,7,3 the function should return 3, because at odd indices there are -4 and 7.

  17. Write a function countMatching that takes as arguments an integer array, the array size, and a pointer to a function predicate. The function predicate takes an integer as an argument and returns a value of 0 or 1, indicating whether the number satisfies a specified condition. The function countMatching should count and return the number of elements in the array that satisfy the condition. Create a test case. Example: for a function f(x)=1 for even numbers, f(x)=0 for odd numbers, and the array {2,7,8,3,10} the function should return 3.

  18. Write a function productPositive that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should return the product of all positive elements in the array. If the array contains no positive elements, the function should return 1. Create a test case. Example: for the array {3,-2,5,0,-1,4} the function should return 60.

  19. Write a function countDivisible that takes three arguments: a positive integer n, an n-element array tab of elements of type int, and a positive integer divisor. The function should return the count of array elements that are divisible by divisor. Create a test case. Example: for the array {12,7,-9,15,4,21} and divisor=3 the function should return 4.

  20. Write a function replaceWithFactorial that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should replace the value of each array element with the factorial of the absolute value of that element. For values greater than 12, the element should be replaced with the value -1. Create a test case. Example: array {3,-4,0,5,15} → {6,24,1,120,-1}.

  21. Write a function getMaximumValue that takes as arguments a non-empty integer array, the array size, and a pointer to a function isValid. The function isValid takes an integer and returns 0 or 1. The function getMaximumValue should find the largest value among the array elements that satisfy the condition and return it. If no element satisfies the condition, the function should return 0. Create a test case. Example: for f(x)=1 when x%3==0 and the array {7,9,4,12,6} the function should return 12.

  22. Write a function sumOfDivisors that takes two arguments: a positive integer n and an n-element array tab of elements of type int. The function should replace the value of each array element with the sum of all positive divisors of the absolute value of that element (including the number itself). Create a test case. Example: array {6,-12,1,7,-8} → {12,28,1,8,15}.

  23. Write a function sumEvenIndices that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should return the sum of elements located at even index positions (0, 2, 4, …). Create a test case. Example: for the array {10,3,7,-2,5,8} the function should return 22.

  24. Write a function multiplyByDigitSum that takes two arguments: a positive integer \(n\) and an \(n\)-element array tab of elements of type int. The function should replace the value of each array element with the product of that value and the sum of the digits of the absolute value of that element. Create a test case. Example: array {12,-34,5,100,-7} → {36,-238,25,100,-49}.
